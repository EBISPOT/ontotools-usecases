# OXO-07: See which mapping sets OxO holds and browse one

**Question:** Where do OxO's mappings come from? Which mapping sets does it hold, what is in a particular set, and how do I search within just that set?

**Tools:** [OxO](https://www.ebi.ac.uk/spot/oxo)

**You need:** nothing to start with; or the name of a source you are interested in (for example *MGI* or *Biomappings*).

**You get:** the list of mapping sets, the description and contents of the one you choose, and searches limited to it.

## Background

OxO loads its mappings from **mapping sets**: published collections of mappings in the [SSSOM](https://mapping-commons.github.io/sssom/) format. There are two kinds:

- **Ontologies** — the cross-references that an ontology publishes about its own terms, extracted from the ontologies in OLS;
- **Curated sets** — mapping files published in their own right, such as Biomappings or the mouse–human phenotype mappings produced by MGI.

OxO's own inferences form one further set, `https://www.ebi.ac.uk/oxo2/inferences`.

## Steps

### On the website

1. Open <https://www.ebi.ac.uk/spot/oxo>. The **Data Content** box shows the date of the data release, the number of mappings (asserted and inferred) and the number of mapping sets (curated sets and ontologies).
2. Click **▸ More options**, then **Choose specific mapping sets…**. A picker opens with two tables:
   - **Curated sets**, with the columns **Title**, **Mapping Set Id**, **Description** and **Provider**;
   - **Ontologies**, with the columns **Ontology**, **Prefix** and **Obsolete**.
3. Find a set by typing into the filter box under a column heading (for example `MGI` under **Title**), or sort a column by clicking its heading.
4. Click a row to select the set; click it again to deselect it. You can select several. With nothing selected, every set is searched.
5. To search within the selected set or sets, enter a term (or choose **From ontologies** / **To ontologies**) and click **Search**. Only mappings that belong to the selected sets are returned.
6. To read about a set, click its name in the **Mapping set** column of any results table. The set's own page shows its title, whether it is asserted or inferred, its description, its identifier and, where published, its provider and creators — followed by a table of all the mappings in the set.
7. On the set's page, use the column filters to look around, and the download icon to save the set's mappings as an SSSOM file.

### With the API

List all mapping sets:

```bash
curl -s 'https://www.ebi.ac.uk/spot/oxo/api/v2/mapping-sets'
```

Each entry has a `mapping_set_id`, `mapping_set_title`, `mapping_set_description` and `mapping_set_category` (`ONTOLOGY` or `CURATED`).

Fetch one set's description (the identifier is passed URL-encoded):

```bash
curl -s 'https://www.ebi.ac.uk/spot/oxo/api/v2/mapping-sets/by-id?mappingSetId=https%3A%2F%2Fw3id.org%2Fsssom%2Fcommons%2Fmouse-human%2Fmappings%2Fmp_hp_mgi_all.sssom.tsv'
```

Search within one set:

```bash
curl -s -X POST 'https://www.ebi.ac.uk/spot/oxo/api/v2/mappings/search' \
  -H 'Content-Type: application/json' \
  -d '{
        "queries": ["MP:0000702"],
        "mappingSetIds": ["https://w3id.org/sssom/commons/mouse-human/mappings/mp_hp_mgi_all.sssom.tsv"],
        "page": 0,
        "size": 100,
        "groupBySpo": true
      }'
```

Get the totals shown in the **Data Content** box:

```bash
curl -s 'https://www.ebi.ac.uk/spot/oxo/api/v2/data-content'
```

## Example

At the time of writing OxO held 373 mapping sets — 65 curated sets and 308 ontologies — with about 29 million mappings, of which 13.8 million asserted and 15.1 million inferred.

One of the curated sets is **All mappings of MP terms to HPO terms generated by MGI**, identifier `https://w3id.org/sssom/commons/mouse-human/mappings/mp_hp_mgi_all.sssom.tsv`. Its page lists 1,524 mappings between Mammalian Phenotype (MP) terms and Human Phenotype Ontology (HP) terms, curated by MGI — for example `MP:0000702` (*enlarged lymph nodes*) `SKOS:exactMatch` `HP:0002716` (*Lymphadenopathy*).
Open the set's page: <https://www.ebi.ac.uk/spot/oxo/mapping-set?id=https%3A%2F%2Fw3id.org%2Fsssom%2Fcommons%2Fmouse-human%2Fmappings%2Fmp_hp_mgi_all.sssom.tsv>

## Good to know

- Not every curated set has a title; some are listed by their identifier only. Filter on **Mapping Set Id** or **Description** to find those.
- Ontology sets whose terms are all obsolete are hidden in the picker unless **Obsolete terms** is ticked under **More options → Also show**.
- OxO's inferred mappings belong to a set of their own, so a search restricted to chosen mapping sets returns only what those sets themselves state. This differs from the **Ontologies** / **Curated sets** choice above the picker, which leaves inferred mappings in (see [OXO-05](OXO-05-filter-by-evidence.md)).
- A set's page counts individual mappings. A search results table counts rows, and can fold several identical mappings into one row, so the two numbers can differ slightly.
