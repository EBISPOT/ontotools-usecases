# OXO-05: Keep only the mappings that meet your evidence requirements

**Question:** OxO returns many mappings for my term. How do I keep only the ones I am prepared to use — for example only published ones, only exact matches, or only those a curator made by hand?

**Tools:** [OxO](https://www.ebi.ac.uk/spot/oxo)

**You need:** a search in OxO (see [OXO-01](OXO-01-find-equivalent-terms.md), [OXO-02](OXO-02-map-list-to-target.md) or [OXO-03](OXO-03-all-mappings-between-ontologies.md)).

**You get:** a filtered table, a filtered download, and an address that reproduces the filtered view.

## Steps

### On the website

Run your search, then apply any of the following. Filters combine: a row must pass all of them.

1. **Published mappings only.** Click the filter icon in the **Type** column header and choose **Asserted only**. Choose **SSSOM inference only** to see just the derived ones, or **All** to undo.
2. **A particular kind of match.** Click the filter icon in the **Predicate** header and type, for example, `exactMatch` into the **ID** box, or pick a value from the list offered. The list shows the predicates present in your results, with counts.
3. **A particular way of making the mapping.** Click the filter icon in the **Mapping justification** header and pick, for example, `ManualMappingCuration` to keep mappings made by a curator, or type part of a name.
4. **Short derivations only.** Click the filter icon in the **Distance** header and choose a **Max distance**. With 1 you keep asserted mappings and the inferences that stay within two ontologies.
5. **A particular target.** Click the filter icon in the **Object** header and type a prefix such as `ICD10CM` into the **ID** box — or, better, choose the target in **To ontologies** and search again.
6. **A particular kind of source.** Open **More options** and, under **Where should mappings come from?**, choose **Ontologies** (cross-references that ontologies publish about their own terms), **Curated sets** (mapping files published separately, usually the result of a curation effort) or **Both**. Then click **Search**. To use only named sources, click **Choose specific mapping sets…** (see [OXO-07](OXO-07-browse-mapping-sets.md)).

A coloured dot on a filter icon shows that the column is filtered; each filter has its own **Clear**. The **Clear** button next to **Search** resets everything.

When the table shows what you want, click the download icon to save the mappings that pass your filters, or copy the page's address to keep or share the filtered view.

### With the API

The same choices are fields of the search request:

```bash
curl -s -X POST 'https://www.ebi.ac.uk/spot/oxo/api/v2/mappings/search' \
  -H 'Content-Type: application/json' \
  -d '{
        "queries": ["MP:0000702"],
        "inferenceType": ["ASSERTED"],
        "columnFilters": [
          {"id": "predicate_id", "value": "SKOS:exactMatch", "match": "EXACT"},
          {"id": "mapping_justification", "value": "ManualMappingCuration"}
        ],
        "page": 0,
        "size": 100,
        "groupBySpo": true
      }'
```

| To keep | Add to the request |
|---|---|
| published mappings only | `"inferenceType": ["ASSERTED"]` |
| one predicate | `"columnFilters": [{"id": "predicate_id", "value": "SKOS:exactMatch", "match": "EXACT"}]` |
| one justification | `"columnFilters": [{"id": "mapping_justification", "value": "ManualMappingCuration"}]` |
| distance up to *n* | `"columnFilters": [{"id": "distance", "value": "1"}]` |
| one kind of source | `"mappingSetCategory": ["CURATED"]` or `["ONTOLOGY"]` |
| named mapping sets | `"mappingSetIds": ["<mapping set identifier>"]` |
| particular targets | `"objectPrefixes": ["HP"]` |

## Example

The mouse phenotype *enlarged lymph nodes* (`MP:0000702`) has 33 mappings. Step by step:

| Filter | Rows left |
|---|---|
| none | 33 |
| **Type**: Asserted only | 5 |
| + **Predicate**: `SKOS:exactMatch` | 2 |
| + **Mapping justification**: `ManualMappingCuration` | 1 |

The one that remains is `MP:0000702` `SKOS:exactMatch` `HP:0002716` (*Lymphadenopathy*), from the mapping set *All mappings of MP terms to HPO terms generated by MGI*.

## Good to know

- The **Where should mappings come from?** choice applies to asserted mappings. Inferred mappings combine several sources and are always shown; hide them with the **Type** filter.
- **Asserted only** depends on direction. Mappings are stored in the direction their source published them, and their reverse is an inference with distance 1. If you search from a coding system *into* an ontology and **Asserted only** leaves nothing, use **Max distance** 1 instead (see [OXO-02](OXO-02-map-list-to-target.md)).
- Most sources do not state a confidence, so the **Mapping confidence** column is often empty. An empty cell means "not stated", not "low".
- Sorting a column replaces OxO's own ordering, which puts mappings from ontologies first, then curated sets, then inferences.
- Which columns you have shown or hidden is the one thing the page's address does not record.
